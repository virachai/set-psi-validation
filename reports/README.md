# Reports Directory

Contains snapshot metric files generated by the validation pipeline.

## Naming Convention

- `metrics.json` – holds the latest aggregated metrics (used by dashboards).
- `metrics-YYYYMMDD-HHMMSS.json` – historical snapshots for audit.

## Contents

- `overall_accuracy`
- `rolling_7d` / `rolling_30d`
- `confusion_matrix`
- `history` array with per‑day details.

> **Note**: Treat `metrics.json` as a read‑only pointer; do not edit directly.
